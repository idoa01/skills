# idoa01 Skills

Personal agent skills, including a staged workflow that takes an idea from design to evaluated implementation. The workflow extends the Matt Pocock skills rather than replacing them.

## Language

**Stage**:
One step of the staged workflow: design, spec, implement, or eval.
_Avoid_: phase, step

**Design artifact**:
One of four records that settle the properties of a design after grilling has settled its choices: the semantics table, consumer inventory, cross-check, and claims ledger.
_Avoid_: design doc, deliverable

**Session watermark**:
A greppable line that a session writes to the user to say which Stage it ran and which work it belongs to. Because the session log keeps everything shown to the user, the line becomes searchable there.
_Avoid_: session tag, session marker
